                    Ranbooru Reforge 插件使用说明
═══════════════════════════════════════════════════════════════════════════════

【插件简介】
Ranbooru 是一个为 Stable Diffusion WebUI (AUTOMATIC1111/Forge) 设计的扩展插件，
能够从各大 Booru 图站（Gelbooru、Danbooru、Safebooru 等）随机抓取图片标签，
自动生成高质量的 AI 绘图提示词，支持 Img2Img、Deepbooru 自动打标、LoRA 随机
混用等高级功能。

【核心功能】
1. 多站点支持：Gelbooru、Rule34、Safebooru、Danbooru、Yande.re、Konachan、
   AIBooru、XBooru、e621
2. 智能标签处理：去重、打乱、过滤坏标签、下划线转空格
3. 提示词生成：随机抽取、混合多个提示词、限制标签数量
4. 图生图模式：支持 Denoising、ControlNet、Deepbooru 自动打标
5. LoRA 随机器：自动从文件夹随机选择 LoRA 并设置权重
6. 标签缓存系统：批量爬取标签到本地，离线顺序使用
7. 高级模式：Chaos 模式、Negative 模式、同种子批量生成

═══════════════════════════════════════════════════════════════════════════════
                              基础使用流程
═══════════════════════════════════════════════════════════════════════════════

【第一步：启用插件】
1. 在 WebUI 界面底部找到 "Ranbooru" 折叠面板
2. 展开面板，勾选 "Enabled" 复选框

【第二步：选择 Booru 站点】
- 下拉菜单选择数据源（推荐新手使用 Safebooru - 全年龄内容）
- Gelbooru/Rule34 需要 API 凭证（见下方"API 凭证配置"）

【第三步：设置搜索标签】
- 在 "Tags to Search (Pre)" 输入框填写搜索标签（逗号分隔）
  示例：1girl,blue_eyes,long_hair
- 留空则随机抽取该站点的所有图片

【第四步：生成提示词】
- 点击 "生成提示词" 按钮
- 生成的标签会显示在 "提示词输出" 框
- 同时自动填入 WebUI 的主提示词框

【第五步：开始生成图片】
- 设置其他生成参数（模型、采样器、尺寸等）
- 点击 "Generate" 开始生成

                            参数详细说明
═══════════════════════════════════════════════════════════════════════════════

【基础参数】
┌─────────────────────────────────────────────────────────────────────────────
│ Booru                  选择数据源站点
│ Max Pages              随机选择的最大页面数（1-9999）
│ Post ID                指定图片 ID（留空则随机）
│ Tags to Search (Pre)   搜索标签（逗号分隔，如：1girl,smile）
│ Tags to Remove (Post)  生成后移除的标签（支持通配符 * 如 hair*）
│ Mature Rating          内容分级（All/Safe/Questionable/Explicit）
└─────────────────────────────────────────────────────────────────────────────

【标签处理】
┌─────────────────────────────────────────────────────────────────────────────
│ Remove bad tags        移除水印、文字、打码等无用标签（推荐开启）
│ Shuffle tags           随机打乱标签顺序
│ Convert "_" to spaces  将下划线转为空格（blue_eyes → blue eyes）
│ Limit tags             保留标签比例（0.05-1.0，1.0 为全部保留）
│ Max tags               最大标签数量（1-100）
└─────────────────────────────────────────────────────────────────────────────

【背景与色彩】
┌─────────────────────────────────────────────────────────────────────────────
│ Change Background      
│   - Don't Change       不改变背景
│   - Add Background     添加背景（outdoors/indoors）
│   - Remove Background  移除背景，添加纯色背景
│   - Remove All         移除所有背景相关标签
│
│ Change Color
│   - Don't Change       不改变色彩
│   - Colored            移除黑白相关标签
│   - Limited Palette    添加有限色板效果
│   - Monochrome         添加单色/黑白效果
└─────────────────────────────────────────────────────────────────────────────

【排序方式】
┌─────────────────────────────────────────────────────────────────────────────
│ Sorting Order
│   - Random             随机选择
│   - High Score         优先选择高分图片
│   - Low Score          优先选择低分图片
└─────────────────────────────────────────────────────────────────────────────

【其他选项】
┌─────────────────────────────────────────────────────────────────────────────
│ Use same prompt for all images    批次中所有图片使用相同提示词
│ Fringe Benefits (Gelbooru)        启用 Gelbooru 隐藏内容
│ Use cache                          启用请求缓存（加速重复搜索）
└─────────────────────────────────────────────────────────────────────────────

                          高级功能详解

【一、Img2Img 模式】
启用后，插件会下载 Booru 图片作为 img2img 的输入图像。

参数说明：
┌─────────────────────────────────────────────────────────────────────────────
│ Use img2img                启用图生图模式
│ Send to Controlnet         发送到 ControlNet（需安装 ControlNet 扩展）
│ Denoising                  重绘幅度（0.05-1.0）
│ Use last image as img2img  使用上一次生成的图片
│ Crop Center                居中裁剪图片
│ Use Deepbooru              使用 Deepbooru 自动打标
│ Deepbooru Tags Position    Deepbooru 标签位置
│   - Add Before             添加到提示词前面
│   - Add After              添加到提示词后面
│   - Replace                替换原提示词
└─────────────────────────────────────────────────────────────────────────────

使用流程：
1. 勾选 "Use img2img"
2. 设置 Denoising 强度（推荐 0.5-0.75）
3. 可选：勾选 "Use Deepbooru" 自动识别图片内容
4. 生成时会先下载图片，然后进行 img2img 生成

【二、文件驱动模式】
从本地文本文件读取搜索/移除标签，方便管理大量标签。

文件位置：
- 搜索标签：user/search/tags_search.txt
- 移除标签：user/remove/tags_remove.txt

使用方法：
1. 在对应文件夹创建 .txt 文件
2. 每行一个标签组合（逗号分隔）
3. 勾选 "Use tags_search.txt" 或 "Use tags_remove.txt"
4. 从下拉菜单选择文件
5. 点击 "Refresh" 刷新文件列表

示例 tags_search.txt：
1girl,blue_eyes,long_hair
1boy,short_hair,smile
2girls,sisters,twins

【三、Extra 额外模式】

┌─────────────────────────────────────────────────────────────────────────────
│ Mix prompts              混合多个图片的标签
│ Mix amount               混合数量（2-10）
│ 
│ Chaos Mode               混沌模式
│   - None                 不启用
│   - Chaos                将部分标签移到负面提示词
│   - Less Chaos           轻度混沌（不影响原负面提示词）
│ Chaos Amount %           混沌比例（0.1-1.0）
│
│ Negative Mode            负面模式
│   - None                 不启用
│   - Negative             将生成的标签全部移到负面提示词
│
│ Use same seed            批次中所有图片使用相同种子
└─────────────────────────────────────────────────────────────────────────────

【四、LoRAnado - LoRA 随机器】
自动从指定文件夹随机选择 LoRA 并设置权重。

参数说明：
┌─────────────────────────────────────────────────────────────────────────────
│ Lock previous LoRAs      锁定上一轮使用的 LoRA
│ LoRAs Subfolder          LoRA 文件夹路径（相对或绝对路径）
│ LoRAs Amount             随机选择的 LoRA 数量（1-10）
│ Min/Max LoRAs Weight     LoRA 权重范围（-1.0 到 1.0）
│ LoRAs Custom Weights     自定义权重（逗号分隔，如：0.5,0.8,1.0）
└─────────────────────────────────────────────────────────────────────────────

使用示例：
1. 设置 LoRAs Subfolder 为 LoRA 文件夹路径
2. 设置 LoRAs Amount = 2（随机选择 2 个 LoRA）
3. 设置权重范围 Min=0.5, Max=1.0
4. 生成时会自动添加如：<lora:style1:0.7><lora:char2:0.9>

【五、Tag 缓存管理系统】★ 重要功能
批量爬取标签到本地数据库，实现离线顺序使用，避免重复联网。

功能特点：
- SQLite 数据库存储，稳定可靠
- 支持追加/覆盖模式
- 顺序输出，支持循环播放
- 搜索、查看、删除缓存条目
- 生成时自动注入缓存标签

使用流程：

【步骤 1：批量爬取】
1. 设置好 Booru、搜索标签、过滤选项
2. 设置 "爬取页数"（建议 5-20 页）
3. 勾选 "追加模式" 或不勾选（覆盖模式）
4. 点击 "🚀 开始批量爬取"
5. 等待爬取完成，查看结果

【步骤 2：查看缓存状态】
- 点击 "🔄 刷新状态" 查看当前索引和总数
- 显示格式：索引: X / 总数: Y

【步骤 3：手动测试】
- 点击 "▶ 取出下一条" 查看当前标签
- 点击 "▶ 取出并设置到提示词" 直接填入主提示词框
- 勾选 "循环播放" 可在到达末尾后自动从头开始

【步骤 4：生成时使用缓存】★ 核心功能
1. 勾选 "生成时使用此缓存"
2. 勾选 "生成时循环读取" （推荐）
3. 在主界面设置 Batch count 和 Batch size
4. 点击 Generate 生成
5. 插件会自动为每张图按顺序注入一条缓存标签

重要说明：
- 启用缓存生成后，会跳过联网抓取，直接使用本地缓存
- 每张图使用不同的缓存标签（按索引顺序）
- 索引会自动保存到硬盘，下次继续
- 支持 Hires.fix（第二段不会重复注入）

【步骤 5：管理缓存】
- 搜索：输入关键词，点击 "🔍 搜索"
- 填充：选择 ID，点击 "📝 填充到输出"
- 删除单条：选择 ID，点击 "🗑️ 删除此条"
- 重置索引：点击 "🔁 重置索引" 从头开始
- 删除全部：点击 "🗑️ 删除全部缓存"

缓存文件位置：
user/cache/tag_cache.db

【Gelbooru / Rule34 API 配置】
这两个站点需要 API 凭证才能访问完整内容。

获取凭证：
1. 注册 Gelbooru/Rule34 账号
2. 登录后进入账号设置页面
3. 找到 API Key 和 User ID

配置方法：
1. 选择 Booru 为 "gelbooru" 或 "rule34"
2. 面板会显示 "API Credentials" 区域
3. 输入 API Key 和 User ID
4. 勾选 "Save credentials" 保存凭证
5. 凭证会保存到：user/credentials/credentials.json

清除凭证：
- 点击 "Clear saved credentials" 按钮

安全提示：
- 凭证文件存储在本地，不会上传
- 建议不要分享 credentials.json 文件

═══════════════════════════════════════════════════════════════════════════════
                          Tag Categories 标签分类
═══════════════════════════════════════════════════════════════════════════════

部分 Booru 站点（Danbooru、Safebooru、AIBooru、e621）支持按标签类型筛选。

可选类型：
┌─────────────────────────────────────────────────────────────────────────────
│ general      通用标签（发色、眼色、服装、动作等）
│ character    角色名称
│ copyright    作品版权（动漫、游戏名称）
│ artist       画师名称
│ meta         元数据标签（分辨率、文件类型等）
└─────────────────────────────────────────────────────────────────────────────

使用方法：
1. 选择支持的 Booru 站点
2. 勾选需要的标签类型（默认：general, character, copyright）
3. 生成时只会包含选中类型的标签

推荐配置：
- 只要角色和通用标签：勾选 general + character
- 排除画师标签：不勾选 artist
- 排除元数据：不勾选 meta

═══════════════════════════════════════════════════════════════════════════════
                          使用技巧与建议
═══════════════════════════════════════════════════════════════════════════════

【新手推荐配置】
- Booru: Safebooru（全年龄内容）
- Max Pages: 50-100
- Remove bad tags: ✓ 开启
- Shuffle tags: ✓ 开启
- Limit tags: 0.8-1.0
- Max tags: 50-75

【高质量提示词配置】
- Sorting Order: High Score（选择高分图片）
- Remove bad tags: ✓ 开启
- Tag Categories: 只勾选 general + character
- Limit tags: 0.6-0.8（保留主要标签）

【批量生成不重复图片】
1. 使用 Tag 缓存系统批量爬取 50-100 页
2. 勾选 "生成时使用此缓存" + "循环读取"
3. 设置 Batch count × Batch size = 需要的图片数量
4. 每张图会使用不同的标签组合

【Img2Img 参考图生成】
1. 勾选 Use img2img
2. Denoising: 0.5-0.7（保留原图特征）
3. 勾选 Use Deepbooru（自动识别原图内容）
4. Deepbooru Position: Add After（补充细节）

【LoRA 随机实验】
1. 准备多个风格/角色 LoRA
2. LoRAs Amount: 2-3
3. Weight 范围: 0.3-0.8（避免过强）
4. 配合 Mix prompts 使用，创造意外效果

═══════════════════════════════════════════════════════════════════════════════
                          常见问题解答
═══════════════════════════════════════════════════════════════════════════════

Q1: 提示 "No posts found" 怎么办？
A1: - 降低 Max Pages 数值
    - 减少搜索标签数量
    - 更换 Booru 站点
    - 检查网络连接

Q2: 生成的标签太多/太少？
A2: - 调整 "Limit tags" 比例
    - 设置 "Max tags" 上限
    - 使用 Tag Categories 筛选标签类型

Q3: 标签中有很多无用内容（水印、文字）？
A3: - 确保 "Remove bad tags" 已勾选
    - 在 "Tags to Remove" 添加自定义过滤标签
    - 使用 tags_remove.txt 文件批量过滤

Q4: Gelbooru 提示需要 API Key？
A4: - 注册 Gelbooru 账号获取 API 凭证
    - 或使用 Safebooru（无需凭证）

Q5: 缓存系统的索引如何重置？
A5: - 点击 "🔁 重置索引" 按钮
    - 或删除 user/cache/tag_cache.db 文件

Q6: 生成时使用缓存，但标签没有变化？
A6: - 检查是否勾选 "生成时使用此缓存"
    - 确认缓存中有足够的数据
    - 查看控制台日志确认索引推进

Q7: Img2Img 模式下图片下载失败？
A7: - 检查网络连接
    - 某些站点可能需要代理
    - 尝试更换 Booru 站点

Q8: 与其他扩展冲突？
A8: - 已知与 sd-dynamic-prompts 可能冲突
    - 建议暂时禁用冲突扩展
    - 查看控制台错误日志

Q9: 批量生成时每张图都一样？
A9: - 取消勾选 "Use same prompt for all images"
    - 取消勾选 "Use same seed"
    - 确保没有锁定 LoRA

Q10: 如何完全离线使用？
A10: - 使用 Tag 缓存系统提前爬取标签
     - 勾选 "生成时使用此缓存"
     - 不勾选 "Enabled"（跳过联网抓取）
